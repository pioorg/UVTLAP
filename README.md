# Use virtual threads like a pro!

This is a demo project to show some new features of Java™ 21-25, related to virtual threads.

It uses `--enable-preview` and Maven, but you don't need to have Maven installed.

To run this project, you need to have Java™ 25 installed. You can use https://sdkman.io/ and/or https://openjdk.java.net/, https://adoptium.net/, or download it directly in IntelliJ IDEA.
